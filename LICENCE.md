## 🧩 About

**ARK Survival GUI** is a comprehensive mod menu for ARK: Survival Evolved featuring server browser, loot filter, spawn map, taming tracker, base overlay, and resource ESP.

Based on popular mods like **ARK Smart Breeding**, **Dino Depot**, and **Beacon**.

---

## ✨ Features

### 🎮 Core Hacks
- Server Browser — filter and join any unofficial server
- Loot Filter — highlight high-tier loot drops
- Spawn Map — display creature spawns on map
- Taming Tracker — track taming progress and food
- Resource ESP — see nearby resources through walls

### 🎨 Cosmetics & Unlocks
- Skin Unlocker — unlock all skins and cosmetics
- Custom Colors — apply any color to dinos and gear
- Emote Unlocker — access all emotes without achievements

### 🏋️ Practice & Training
- Instant Tame — tame any creature instantly (single-player)
- Infinite Stats — unlimited health, stamina, weight
- No Clip — fly through terrain and structures
- Instant Craft — craft any item without resources
